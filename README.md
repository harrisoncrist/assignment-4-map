This project uses data from the national Home Mortgage Disclosure Act (HDMA) dataset to map loan values in New York City for years 2018 and 2023. 

Data for each year was pulled using filters on the HDMA website. 
That data was then cleaned in R and processed into a GeoJSON file in QGIS. 

Future iterations of the map will do the following:
 - include a new map layer showing the percent change from 2018 to 2023.
 - build out the narrative.
 - add guiding elements (fly to, scroll) that guide the user through how to explore the data.
